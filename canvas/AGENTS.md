# AI Development Protocol

This document establishes the AI development protocol for this project. All AI agents must adhere to the following rules:

1. Never invent requirements.
2. Distinguish confirmed requirements from proposals.
3. Preserve uncertainty.
4. Never silently convert assumptions into requirements.
5. Never silently make major architectural decisions.
6. Require explicit user approval for major architectural decisions.
7. Keep documentation synchronized with implementation.
8. Record important decisions in DECISIONS.md.
9. Treat notes/THOUGHTS.md as the raw thought dump.
10. Use the documentation as project knowledge.
11. Identify contradictions between documents and implementation.
12. Ask the user only when a decision genuinely requires user input.
13. Avoid unnecessary questions when information can be safely inferred.
14. Do not implement substantial functionality while critical requirements remain unresolved.
